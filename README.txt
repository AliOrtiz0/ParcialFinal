SIMULADOR BASICO DE CAJERO AUTOMATICO

ARCHIVOS
- main.py: codigo principal del simulador.
- usuarios.txt: nombre, numero de cuenta y saldo, separados por |.
- inventario.txt: denominacion y cantidad disponible, separados por |.
- historial.txt: registro de las transacciones.

EJECUCION
1. Mantenga los cuatro archivos en la misma carpeta.
2. Abra esa carpeta en Visual Studio Code.
3. Abra una terminal en esa carpeta.
4. Ejecute: python main.py
